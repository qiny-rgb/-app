稚护仓 · 智能药箱网页源代码

这是当前已部署网页的完整静态源代码，解压即可编辑，无需 npm 安装或构建。

文件说明
- index.html：网页入口
- style.css：界面样式
- app.js：首页、药品列表、家庭成员、用药计划、闹钟等交互
- trace.js：本机 OCR 资源加载、文字字段提取等基础功能
- photo.js：当前使用的药盒拍照录入流程与照片存储
- ocr/：本地文字识别引擎、中文/英文字库及许可证
- qrcode.png：指向原 chatgpt.site 地址的二维码。迁移到新域名后请重新生成。
- start-local.py：本机预览脚本（需要 Python 3）

本机打开
1. 解压整个 ZIP 文件，不要只提取 index.html。
2. 安装 Python 3 后，在解压目录打开终端，执行：python start-local.py
   部分系统需执行：python3 start-local.py
3. 在同一台电脑浏览器打开：http://localhost:8000
4. 停止预览：在终端按 Ctrl+C。
不要直接双击 index.html 运行 OCR；浏览器对 file:// 下的 Worker 和资源加载有限制。

迁移部署
这是静态网页，可部署到支持 HTML / JS / WASM 的静态托管服务。
将解压目录中的文件和 ocr 子目录上传至网站根目录，以 index.html 作为首页。
无需上传 Git 历史或配置 ChatGPT 登录。请使用 HTTPS 以支持相机、安全存储等浏览器能力。
WASM 文件建议设置 Content-Type 为 application/wasm。
不要拦截同源 Web Worker、WebAssembly 及 ocr/ 下的字库请求。
部署完成后，请在目标手机浏览器及微信内实际测试拍照、图片读取和 OCR。
中国大陆域名、托管开通、备案和 HTTPS 配置需要另行在服务商办理。

功能与限制
- 拍摄或选择药盒照片，识别20位追溯码与明确标注的有效期，核对后保存。
- 不自动根据生产日期推算有效期，不查询药品真伪。
- 药品、计划、成员等信息保存在 localStorage；照片保存在 IndexedDB。
- 当前没有服务端数据库、账号体系或跨设备同步。清除浏览器数据会清除本地记录。
- 此 ZIP 不包含使用者在浏览器中录入的药品信息、照片或计划。
- 智能药箱的蓝牙连接、固件升级等为演示状态，尚未对接硬件协议。
- 所有 OCR 运行依赖随包附带，不依赖外部 OCR 云服务。
- 第三方许可证随 ocr 目录附带，请保留。

本包不包含任何云平台密码、访问密钥或 Git 凭据。
